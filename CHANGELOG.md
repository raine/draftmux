# Changelog

## Unreleased

First release, for Apple silicon Macs, as a signed and notarized disk image
and a Homebrew cask (`brew install --cask raine/draftmux/draftmux`).

- Draft GitHub, Slack, rich-text and plain-text messages in a Markdown editor
  next to a preview of how the message will look where it goes, and copy it
  out in the target's format.
- Hand a conversation off from Claude Code or pi with the `draftmux` skill
  (`draftmux skill install`), polish the message with an embedded pi agent,
  and let the original agent read the result back with `draftmux show`.
- Rewrite a selection with actions such as Shorter, Tighten and Alternatives,
  or define your own in Settings.
- Keep titles, subjects and recipients in YAML frontmatter fields, each with
  its own copy button.
- Installed copies update themselves from GitHub releases.
